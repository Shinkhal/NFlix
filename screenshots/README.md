# Screenshots

Screenshots for AppStream metadata and store listings.

## Requirements
- PNG format, at least 1248×702 pixels (16:9 recommended)
- Do NOT include copyrighted Netflix content (movie posters, thumbnails, show artwork)
- Safe subjects: the Netflix login page, the app's empty/loading state, or the app's title bar and window frame
- Must accurately represent the application

## Files needed
- `main-window.png` — The main application window (default screenshot)

## Generating
Take a screenshot of the app running with `gnome-screenshot -w` or similar.
Crop to show just the app window.
