# Security policy

## Reporting a vulnerability

Do not report vulnerabilities in public issues. Until a private security contact is configured, contact the repository owner through the private reporting feature provided by the hosting service. Include affected versions, impact, and reproduction steps. Do not include Netflix credentials, cookies, personal data, or DRM license traffic.

## Scope

Reports about the desktop wrapper, packaging, update/build process, and handling of external links are in scope. Netflix service vulnerabilities should be reported to Netflix through its own security program.

## Supported versions

Security fixes are made on the latest development version. There are no release branches yet.
